# Wordstat: PDF → Excel — ключевые слова

> Проверено: 2026-11-11 · источники: Яндекс Wordstat API (`top_requests` + `dynamics`) · регион: Россия (дефолт)

## Вердикт

Основной спрос в РФ пишут кириллицей: **`из пдф в эксель` ~63–64k / 30 дней**. Латиница `pdf в excel` ~14–15k. Спрос стабильно высокий (май’25–сен’26: ~45–69k/мес), без резкого взлёта. Много «онлайн / бесплатно» — DIY-конвертеры; для услуги ценнее хвосты про **таблицу**, **распознать**, **без искажений**, **данные/выгрузить**.

**С чего начать в семантике:** ядро `из пдф в эксель` + коммерческие/проблемные хвосты (таблица, распознать, перенести данные), минус обратное направление Excel→PDF.

## Кластеры для продукта / рекламы

1. **Ядро DIY** — «из пдф в эксель / онлайн / бесплатно / конвертер» (объём огромный, конкуренция сайтов).
2. **Таблица** — «таблица из пдф в эксель / перенести / скопировать / вытащить» (ближе к качественной услуге).
3. **OCR** — «распознать пдф в эксель / текст / без искажений» (сканы; чек выше).
4. **Данные** — «данные / выгрузить / импорт / экспорт в эксель» (B2B-формулировки).
5. **Минус** — всё «эксель в пдф / сохранить excel в pdf».

## Оговорки

- Частоты Wordstat — **поисковые** запросы Яндекса за ~30 дней, не число заказов услуги.
- Группа `из пдф в эксель` (~64k) шире точных вхождений отдельных хвостов; хвосты не суммировать в «суммарный спрос».
- Рост «услуги на биржах» (Fiverr PDF→Excel +153%) и стабильный Wordstat DIY — разные сигналы; здесь только Wordstat.
